---
### Main Vision
The main goal of our project `HAlloReg` is to implement active inference agents that reconcile self-protective behavior with mutual cooperation in social dynamics ($\approx$ Adaptive Prosociality), by endogenously regulating prosociality parameter $\lambda$. It is grounded on:
1. Active inference framework and second-person neuroscience; It was one of the main contributions of `ToMEmpathicAgent` (Albarracin et al., 2026).
2. Allostatic regulation, that is preemptive homeostatic regulation (and also energy regulation). It will be the main focus of `HAlloRegAgent`.    

When hierarchically connected each other, empathic active inference agents can exhibit context-dependent prosocial behaviors, tentatively suggesting evolutionary advantages over long-run cycles under collective social situations.
